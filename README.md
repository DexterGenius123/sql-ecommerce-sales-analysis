# Анализ продаж интернет-магазина

SQL-проект на PostgreSQL: от нормализованной схемы заказов до витрины ежедневных KPI. В отличие от обычной подборки упражнений, запросы отвечают на вопросы продукта и бизнеса: выручка, повторные покупки, когортное удержание и вклад категорий.

## Бизнес-задача

Команде e-commerce нужны воспроизводимые SQL-отчёты, чтобы отслеживать продажи, возвраты, новых и повторных клиентов, а также товары с падающим спросом.

## Технологии и навыки

PostgreSQL · DDL · PK/FK · `JOIN` · `GROUP BY` · CTE · `FILTER` · оконные функции · `DATE_TRUNC` · когортный анализ · materialized view.

## Запуск

```bash
createdb ecommerce_analytics
psql -d ecommerce_analytics -f sql/01_schema.sql
psql -d ecommerce_analytics -f sql/02_seed.sql
psql -d ecommerce_analytics -f sql/03_analysis.sql
```

| Файл | Содержание |
| --- | --- |
| `sql/01_schema.sql` | нормализованная схема и индексы |
| `sql/02_seed.sql` | синтетические данные за три месяца |
| `sql/03_analysis.sql` | 13 аналитических SQL-запросов и витрина KPI |

## Вопросы, на которые отвечает проект

- Как меняются выручка и средний чек по месяцам?
- Кто из клиентов возвращается после первой покупки?
- Какие категории дают наибольшую маржу и чаще возвращаются?
- Какие товары не продавались в последнем месяце?
- Как выглядит retention первой когорты клиентов?

Все данные созданы для демонстрации и не являются данными реального магазина.
